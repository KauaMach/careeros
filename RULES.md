# Regras do Projeto (AI Agent)

1. **Commits Contínuos:**
   - Faça commits de forma contínua a cada nova funcionalidade implementada.
   - Faça commits para cada modificação ou correção "grande".
   - Não acumule muitas alterações (mais de um módulo/etapa) sem antes commitar e enviar (push) para o repositório.
   - Use mensagens de commit claras seguindo o padrão do Conventional Commits (ex: `feat:`, `fix:`, `refactor:`).
